## Project Overview
This project recognizes American Sign Language (ASL) alphabet letters in real time using a webcam. It uses MediaPipe to detect hand landmarks, then a trained machine learning classifier (SVM / Neural Network) to predict the letter being signed.

No large language models or GPU are required — the entire pipeline runs on CPU and is lightweight enough for a MacBook Air.

## How It Works
1. The webcam captures a video frame.
2. MediaPipe detects the hand and extracts 21 landmark points.
3. The landmarks are normalized (relative to the wrist, scaled) so the model works regardless of hand position or distance from the camera.
4. A trained classifier predicts the letter from the normalized landmarks.
5. The predicted letter is displayed on screen in real time.

## Usage

### Step 1: Collect training data
Run this once per letter (A-Y, excluding J and Z which require motion):
```bash
python src/collect_data.py --label A
```
Press `c` to capture a sample (aim for 40-60 samples per letter, varying hand angle slightly), then `q` to move to the next letter.

### Step 2: Train the model
```bash
python src/train_model.py
```
This trains an SVM and a small Neural Network, prints accuracy for both, saves the better one to `models/sign_model.pkl`, and saves a confusion matrix image to `docs/confusion_matrix.png`.

### Step 3: Run real-time recognition (live demo)
```bash
python src/recognize.py
```
Show a hand sign to the webcam; the predicted letter appears on screen. Press `q` to quit.
